# Estructura de Carpetas y Archivos del Proyecto

```text
Carpeta raíz/
|-- .gitignore          # Configuración de Git. Documentos y carpetas ignorados.
|-- astro.config.mjs    # Configuración de astro.
|-- package-lock.json   # Configuración del proyecto completa.
|-- package.json        # Configuración del proyecto rápida.
|-- tailwind.config.mjs # Configuración gráfica Tailwind.
|-- tsconfig.json       # Configuración de Typescript.
|-- .github/
|    |-- deploy.yml     # CI/CD en GitHub Pages.
|-- documentation/      # Carpeta con la documentación del proyecto.
|-- public/
|    |-- .nojekyll    # Desactiva Jekyll en GitHub Pages.
|    |-- avatar.svg   # Imagen vectorial del Hero y Favicon
|    |-- 
|    |-- 
|    |-- 
|    |-- 
```

> Para los archivos de configuración mirar el archivo de documentación `Guía_Astro_in_Github_Pages.md`.
